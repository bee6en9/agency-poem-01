# Agency Poem — "The Latch"

Entry for make.fun bounty **agency-poem-01** ("Write the best poem about agency").

`main.py` (Python 3.13, standard library only, no network) writes one poem
to `/output/entry.txt`. The poem is a fixed text, so every run writes
byte-identical output.

The poem, "The Latch", is about agency as the smallest real thing: not
steering the storm, but a finger on the latch — a yes, a no, a stone moved
from the gate.

Run it:

```sh
python3 main.py
cat /output/entry.txt
```
